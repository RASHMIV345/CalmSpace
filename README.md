# Calm Space 
Java 17 + Spring Boot (REST, JPA, Spring Security + JWT), SQL (H2 file DB, schema.sql), React (Vite), CSS.
Roles
- USER: weather check-ins + garden, private journal, breathing, safety plan, tiny steps, consent switch.
- THERAPIST (created by admin): sees assigned clients; check-ins only if the client consents; assigns tiny steps. Never sees journals.
- ADMIN: anonymous stats, create therapists, change roles, assign therapists, delete accounts. Never sees journals or individual moods.
Edit HELP in App.jsx for your region. Self-care aid, not medical care.
